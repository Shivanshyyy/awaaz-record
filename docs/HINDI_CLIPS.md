# Hindi clips for the patient

The only Hindi in this project. The patient (Noor) hears these short, fixed sentences at the end of her visit, and sees the same Hindi text on her slip. Because the list is fixed, the app can never say anything unchecked to a patient.

**For Claude Code:** copy the Hindi text exactly as written. Never edit it or write new Hindi. If the app needs a new line, add the English meaning at the bottom marked `NEEDS TRANSLATION + REVIEW`.

**For Shivansh:** you don't need to read the Hindi. The "English meaning" column tells you what each clip says. Get a Hindi speaker to confirm it (see the review log at the bottom).

## Playlist rules (for Claude Code)

`consent` plays on its own, before recording. After the record is confirmed, the playlist is built in this order:

1. `intro` — always.
2. Medicine timing — only if there are medicines:
   - all medicines share the same frequency and none is "when needed": perDay 1 → `med_1x` (or `med_1x_night` if the timing is night), perDay 2 → `med_2x`, perDay 3 → `med_3x`;
   - otherwise (different frequencies, any prn, or perDay ≥ 4) → `med_multi`.
3. `med_after_food` — if any medicine has withFood = after.
4. `med_finish` — optional, unticked by default; the worker ticks it.
5. Advice: tag fluids → `adv_water`, rest → `adv_rest`, breastfeeding → `adv_breastfeed`.
6. Referral: `ref_go` if there's a referral; add `ref_today` if it's urgent.
7. Follow-up: days 3 / 5 / 7 / 14 / 30 → `fu_3` / `fu_5` / `fu_7` / `fu_14` / `fu_30`; any other number of days or a date → `fu_slip`; `if_worse` or `none` → no follow-up clip.
8. `worse` — on by default (the worker can untick it).
9. `keep_slip` — on by default.
10. `outro` — always.

The worker always sees the list with the English meaning of each clip before pressing play, and can untick optional clips.

Files: `public/audio/hi/<ID>.mp3` (e.g. `public/audio/hi/med_2x.mp3`). Fallback when a file is missing: speak the Hindi text with the device's `hi-IN` voice if it has one; otherwise show the Hindi text and "audio not available".

## Making the clips in ElevenLabs (Shivansh)

1. **First**, have a Hindi speaker read this file (5–10 minutes) and fix any wording before you generate audio. Fixing text is free; regenerating audio isn't.
2. Pick a voice that sounds natural in Hindi. Test it on the `consent` line first and ask your Hindi speaker if it sounds right.
3. Paste one Hindi line at a time (the Devanagari text, not the romanized one). If you can, set the speed slightly slower than normal for clarity.
4. Download each as MP3 and rename it to its ID, e.g. `consent.mp3`, `med_2x.mp3`.
5. Put all 23 files in `public/audio/hi/`, then paste Prompt 5 into Claude Code.
6. Ask your Hindi speaker to listen to all 23 clips while reading the English meanings. Note any clip that sounds wrong, regenerate it, and fill in the review log.
